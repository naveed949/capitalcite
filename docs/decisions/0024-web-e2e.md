# 0024. Browser proof and a pinned proxy

Date: 2026-10-23

Status: Accepted

Someone analysing bank financials asks a question on the page and
needs a cited span, a refusal, a gated tool, or a cancel that
actually stops the run. The page already streams that answer. This
record is why the proof is Playwright against `next start`, why
Chromium is the only CI browser, why the proxy pins the model and
caps the body, and how cancel reaches uvicorn.

## Playwright, not Cypress, not Selenium

The page is one screen. The client is `fetch` plus a
`ReadableStream`. `verify-browser.mjs` already imports `playwright`
and launches Chromium. `@playwright/test` is that same library with
a runner, a trace, and an HTML report. A clean clone can import it
because it is a `web` devDependency.

Cypress would be a second runner and a second assertion API for the
same Chromium the verify helper already starts. Selenium would add a
driver stack for that same browser. Neither changes what a citation
chip or a cancel can prove.

## Chromium only in CI

The product path is Chromium. Firefox and WebKit would add another
browser download and another job without a second engine the page
claims to support. CI caches `~/.cache/ms-playwright` so the install
is not a cold download on every PR.

## `next start`, not `next dev`

`next dev` compiles on request. It can hold a stream until the
compiler finishes a rebuild. ADR 0020 set `compress` to false so the
dev server does not gzip `text/event-stream`. `next start` is the
server that runs after `next build`. The `e2e` job and `verify.sh`
start that server. A green check is the production page.

## Cancel across the browser, the proxy, and the API

The user clicks Cancel. `useAsk` aborts its `AbortController`.
`askStream` stops reading. `sseFrames` calls `reader.cancel()` in
`finally`, so the response body is released. The Next route forwards
`request.signal` on the upstream fetch. `_AskSSEResponse` watches
ASGI `http.disconnect` before it peeks the first event. A cancel
during retrieve cancels that task. The page shows Cancelled. The
Playwright spec also reads the API log for the line `ask stream
cancelled by client`. A UI abort that never reaches uvicorn is not
this check.

A malformed frame yields a transport fault, and the hook publishes
that fault, before it aborts. The session stays `failed`. Aborting
first would show Cancelled.

`Settings.capitalcite_test_slow_retrieve_ms` defaults to 0. The env
name is `CAPITALCITE_TEST_SLOW_RETRIEVE_MS`. The sleep runs only
when that value is greater than 0 and the question is `Hold this
retrieve so cancel can land`. Other questions do not wait.
Production leaves the value at 0.

## The model is pinned on the server

The browser used to send `model`, and the proxy forwarded the body
unread. A page on the public internet could post `openai` and spend
a key the operator did not give that browser. The Next route now
drops the client field and writes `model` from `ASK_MODEL` on the
Next process. The value is `openai` only when that env is exactly
`openai`. Every other value, including unset, is `fake`. The demo
label reads the same env. curl and MCP still send `model` to FastAPI
directly.

## A body cap at the proxy and at the API

The proxy used to forward the unread body. A 60 MB JSON question was
legal, because `AskRequest.question` only required `min_length=1`.
The proxy now reads the body and returns 413 with
`{"detail":"payload too large"}` above 16 KiB. `AskRequest.question`
has `max_length=8000` and returns 422. The proxy cap is the byte
length of the HTTP body. The API cap is the character length of the
question. A caller that skips Next still cannot place a filing-sized
string in the prompt.

An unreachable API used to raise inside the route handler. The proxy
catches that fetch and returns 502 with
`{"detail":"upstream unavailable"}`. The body has no traceback.

## Gate deny is a file

The e2e job points `GATE_POLICY` at
`web/e2e/fixtures/deny-search.json`. That file is version 1, default
deny, and an empty `tools` map. The gate already denies a tool that
is not in the map, with reason `unknown_tool`. The timeline shows
that reason. The shipped `src/capitalcite/gate/tools.json` is
unchanged. `verify.sh` does not set `GATE_POLICY`, so its agent
check still sees `search_filings`.

## Node 22

Playwright and Next 16 need Node 22.19 or newer. `.nvmrc` is `22`.
`web/package.json` sets `engines.node` to `>=22.19.0 <23`. The e2e
job reads `.nvmrc`.
